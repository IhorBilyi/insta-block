# insta-block

A Reels-free Instagram. It loads instagram.com and strips out Reels with an injected script, so there's
no patched Instagram app and far less ban risk.

- [`web/`](web/): the blocker itself, as a userscript you can use in any browser today.
  Its `dist/blocker.js` and `dist/blocker.css` are what the iOS app injects.
- `ios/`: the iOS app (not started yet).
